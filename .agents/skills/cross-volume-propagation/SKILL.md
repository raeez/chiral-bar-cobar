2. Check theorem statements, proofs, summaries, examples, remarks, introductions, and appendices.
3. Check build-facing surfaces:
   labels,
   references,
   citation claims,
   metadata.
4. Check compute-facing surfaces:
   docstrings,
   hardcoded expected values,
   tests.
5. Update verified live duplicates within assigned paths. Report other owners' exact dependent paths.

- Volume I uses OPE-mode formulas frequently.
- Volume II uses lambda-brackets with divided powers.

Never propagate by verbal similarity alone. Convert conventions first.
